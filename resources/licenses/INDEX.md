## Redistribution status vocabulary

| Status | Meaning |
|---|---|
| `permitted` | Permissive licence (MIT, Apache-2.0, BSD, ISC). Copy with attribution and licence text retained. |
| `permitted-with-copyleft-notice` | Copyleft (GPL/AGPL/LGPL/MPL). Copying is allowed; copyleft obligations attach if the material is combined into a distributed work. |
| `permitted-cc-by` / `permitted-cc-by-sa` | Creative Commons. Attribution required; ShareAlike additionally requires adaptations of THAT material to carry the same licence. |
| `permitted-non-production-only` | Business Source License 1.1: non-production use only until the change date. |
| `permitted-no-sell` | Commons Clause: redistribution allowed, selling the software is not. |
| `permitted-with-additional-terms` | Apache-2.0 plus extra conditions; read them before commercial use. |
| `permitted-use-restricted` | Modified OpenRAIL-M: applies to MODEL WEIGHTS (none were downloaded). Use restrictions apply. |
| `permitted-except-enterprise-dir` | MIT except a named directory, which was not collected. |
| `permitted-scoped` | Composite licence covering specific directories; only files inside covered directories were collected. |
| `permitted-registry-metadata` | Factual package-registry metadata from the public PyPI JSON API; no package code bundled. |

## Deliberately NOT collected


- Model weights of any kind (explicit instruction; also a licence-per-model question).
- Dataset archives and benchmark data hosted on huggingface.co (host unreachable for download from the build sandbox).
- arXiv paper PDFs (host unreachable for download; the arXiv non-exclusive distribution licence does not grant third-party redistribution).
- Third-party copyrighted text bundled inside permissively-licensed repositories — specifically the Paul Graham essays
  shipped as haystack text in `gkamradt/needle-in-a-haystack` and referenced by URL list in `NVIDIA/RULER`, and the
  arXiv PDFs used as test fixtures in `docling-project/docling` and `Unstructured-IO/unstructured`. Those files inherit
  the PAPER or ESSAY licence, not the repository licence.
- `yixuantt/MultiHop-RAG`: no upstream licence file exists, so there is no redistribution right. Two files downloaded in an
  early pass were deleted during the licence audit; see `resources/documentation/_metadata-only/multihop-rag.md`.
- `hudson-and-thames/mlfinlab`: proprietary Copyright Protection Notice.
- Copyrighted books (López de Prado, *Advances in Financial Machine Learning*; the print text of Jansen, *Machine Learning for Trading*).
- Vendor pricing/terms pages (frequently changed, not redistributable; a stale copy is worse than a link).
